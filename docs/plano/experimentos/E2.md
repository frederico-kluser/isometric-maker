> **Quick Start (TL;DR)**: Experimento do card I-02 — ver PLANO-DE-EXECUCAO.md seção I-02.

**Data:** 2026-07-31

## Pergunta

1. `walking-4-frames` existe como template_animation_id?
2. ID inválido dá 422 antes ou depois de cobrar?

## Válido: `walking-4-frames`

```json
POST /v2/animate-character
{"character_id":"b47d950d-9863-456c-896f-d043f258f933","mode":"template","template_animation_id":"walking-4-frames","directions":["south"],"seed":424242}
```

- **job_id:** `de780d10-3515-4ea6-a308-63fb2188a525`
- **status:** completed
- **usage:** `{"seconds": 83.78609871864319}` (1 geração, ~US$ 0.014)

## Inválido: `isto-nao-existe`

```json
POST /v2/animate-character
{"character_id":"b47d950d-9863-456c-896f-d043f258f933","mode":"template","template_animation_id":"isto-nao-existe","directions":["south"],"seed":424242}
```

- **Resposta:** 422 value_error
- **usage:** Nenhum (sem job criado)
- **Lista truncada:** `angry`, `attack`, `attack-back`, `attack-left`, `attack-right`, `backflip`, `bark`, `breathing-idle`, `cross-punch`, `crouched-walking`, `...`

## Veredicto

- `walking-4-frames` é um template válido (fora do prefixo visível de 10)
- Validação de `template_animation_id` é **pré-submissão**: ID inválido retorna 422 sem criar job, sem cobrar nada
- A lista truncada com `...` é literalmente do fornecedor — existem mais templates além dos 10 visíveis
