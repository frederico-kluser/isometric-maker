# E1 — O que `isometric: true` faz

> **Quick Start (TL;DR)**: Experimento do card I-02 — ver PLANO-DE-EXECUCAO.md seção I-02.

**Data:** 2026-07-31

## Pergunta

O campo `isometric` muda a projeção de verdade, apenas enviesa o prompt, compõe com `view` ou o sobrescreve? As 8 direções continuam as mesmas?

## Corpos enviados

### Sem isometric

```json
POST /v2/create-character-with-8-directions
{"description":"bald naked humanoid mannequin, neutral skin, no clothing, plain body, pixel art","image_size":{"width":64,"height":64},"view":"low top-down","mode":"standard","seed":424242}
```

- **character_id:** `b47d950d-9863-456c-896f-d043f258f933`
- **job_id:** `3c291feb-f7c1-4d69-a130-fd903aaa49df`
- **usage:** `{"seconds": 99.34321427345276}` (sem campo `type`)
- **status:** completed

### Com isometric

```json
POST /v2/create-character-with-8-directions
{"description":"bald naked humanoid mannequin, neutral skin, no clothing, plain body, pixel art","image_size":{"width":64,"height":64},"view":"low top-down","mode":"standard","seed":424242,"isometric":true}
```

- **character_id:** `c6e142ee-6166-4f5d-83ac-0dd3cf254439`
- **job_id:** `47e93cc7-f59f-4d0b-ad2a-ab2a8d6b02a6`
- **usage:** `{"type": "generations", "generations": 1.0}`, `{"seconds": 134.5246238708496}`
- **status:** completed

## Veredicto

- `isometric: true` custa **1 geração** em mode `standard` (campo `usage.type = "generations"`)
- O campo muda a projeção — os ângulos e proporções são diferentes entre os dois resultados
- `direction_count` a confirmar: comparar `rotation_urls` de ambos

## Usage cru

### Sem isometric

```json
{"seconds": 99.34321427345276}
```

### Com isometric

```json
{"type": "generations", "generations": 1.0}
{"seconds": 134.5246238708496}
```
